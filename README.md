# 📇 ContactBookApp

A mobile contact management application built with **React Native** and **TypeScript**.  
This app allows users to store, view, and manage contacts directly from a mobile interface.

## 🚀 Features

- Add new contacts
- View saved contacts
- Edit existing contacts
- Delete contacts
- Mobile-friendly interface
- Local data persistence with Realm
- Navigation between screens
- Network state handling with NetInfo

## 🛠️ Technologies Used

- React Native
- TypeScript
- React Navigation
- React Native Paper
- Realm
- React Native Vector Icons
- NetInfo
- Jest
- ESLint
